# UI Improvements - 50 Ideas

Generated by 15-agent research team on 2026-04-20.

## Chat (6)

1. **Code block border radius mismatch** - `lib/features/chat/markdown/markdown_view.dart:118-128` - Code blocks use `AppRadius.sm` (8px) while bubbles use `AppRadius.xl` (20px). Increase code block radius to match.

2. **Tool view vertical padding too tight** - `lib/features/chat/tools/tool_view.dart:609-627` - 1px vertical gap between stacked tools. Increase to `AppSpacing.xs` minimum.

3. **Message bubble group spacing inconsistent** - `lib/features/chat/widgets/user_bubble.dart:52-57` - 2px gap between grouped messages too tight. Add `isInGroup` parameter for 1px intra-group, 8px inter-group spacing.

4. **Chat loading shimmer uses fixed heights** - `lib/features/chat/widgets/chat_loading_shimmer.dart:33-35` - Use randomized heights to simulate natural message variability.

5. **Missing accessibility labels on bubbles** - `lib/features/chat/widgets/user_bubble.dart:49-103` - Add `Semantics` labels for screen readers.

6. **Input hint text contrast issue** - `lib/features/chat/chat_input.dart:537-545` - Hint at 0.5 opacity may fail WCAG AA. Use `cs.onSurfaceVariant` at 0.6.

## Sessions (4)

7. **Session cards inconsistent height** - `lib/features/sessions/` - Vary card height based on message preview length.

8. **Date headers need better hierarchy** - `lib/features/sessions/` - "Today"/"Yesterday" headers should use smaller font weight.

9. **Machine picker lacks offline indicator** - `lib/features/sessions/` - Add visual dot showing machine online/offline status.

10. **Session creation dialog spacing** - `lib/features/sessions/` - Optimize vertical spacing in new session form.
